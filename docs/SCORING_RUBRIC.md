# CareerFit AI — ATS 100-Point Scoring Rubric & Methodology

CareerFit AI implements a transparent, deterministic 100-point scoring model across five distinct categories. Unlike black-box scoring systems, every point awarded is backed by verifiable document features.

---

## 1. Category Breakdown

| Category | Maximum Points | Evaluation Criteria |
|---|---:|---|
| **Category 1: Formatting and Structure** | 20 | Section completeness, optimal document density (450–900 words), bullet point formatting |
| **Category 2: Keyword Relevance** | 25 | Technical terminology density, role-specific benchmark skills, job description coverage |
| **Category 3: Content Quality and Impact** | 20 | Action-oriented verbs, Google X-Y-Z accomplishment structure, quantified metrics |
| **Category 4: Skill Depth** | 20 | Contextual skill evidence in project bullets vs bare lists, multi-domain stack balance |
| **Category 5: ATS File Compatibility** | 15 | Header/contact parseability, clean ASCII text flow, lack of complex nested tables |
| **Total Readiness Score** | **100** | |

---

## 2. Readiness Tiers

- **Strong Readiness (80–100 points)**: High likelihood of seamless ATS parsing and strong keyword matching against target tech roles.
- **Improvement Recommended (60–79 points)**: Parsable with good foundational content, but lacks quantifiable business impact or core benchmark skills.
- **Significant Improvements Needed (0–59 points)**: Severe formatting issues, missing essential sections, or sparse descriptions requiring restructuring.

---

## 3. Google X-Y-Z Pattern

Our AI Bullet-Point Rewriter automatically transforms weak passive statements into high-impact accomplishment bullets:
> **"Accomplished [X] as measured by [Y] by doing [Z]"**

When an AI suggestion suggests a potential percentage or scale placeholder, it is explicitly flagged with `requires_confirmation: true` to prevent hallucinating candidate credentials.
